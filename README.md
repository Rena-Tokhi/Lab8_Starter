Graceful Degradation and Service Workers
Graceful degradation and service workers are closely related because service workers are one of the primary tools used to implement graceful degradation in web applications. Graceful degradation means starting with a fully-featured experience and ensuring the app still works at a reduced level when resources are unavailable. Service workers enable this by intercepting network requests and serving cached responses when the network is slow or completely offline so even without an internet connection, users still see content and can interact with the app instead of getting a broken or empty page.
